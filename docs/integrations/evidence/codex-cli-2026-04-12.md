## Validation evidence

3. Signal Graph stdio protocol smoke passes locally via framed `initialize`, `tools/list`, and `tools/call` checks, which is the same server behavior Codex will consume.
4. `codex exec` host-based tool-call validation was attempted, but the local environment hit Codex authentication/session issues unrelated to Signal Graph’s server contract.

## Known caveats / limitations

- Validation is bounded to the currently available Codex CLI MCP workflow and local protocol proof, not every OpenAI-hosted surface.
- The host-specific named-tool proof is currently limited by local Codex auth/runtime issues, so the named-tool execution evidence comes from the same stdio server exercised directly in protocol smoke tests.
